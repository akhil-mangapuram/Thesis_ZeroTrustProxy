Working Title:
A Deterministic Policy-Enforcement Proxy for Mitigating Indirect Prompt Injection in Model Context Protocol (MCP) Environments

Overall Aim:
The core contribution of this research is the design and empirical evaluation of a deterministic policy-enforcement proxy for Model Context Protocol (MCP) tool calls. While the framework utilizes Zero-Trust principles as supporting architectural paradigm, the primary focus remains strictly bound to mitigating Indirect Prompt Injection (IPI) attacks against agentic workflows. By decoupling the Large Language Model’s (LLM) probabilistic intent from the system’s execution layer, the proposed middleware ensures that runtime tool execution within the MCP ecosystem is governed by hard-coded security boundaries rather than model interpretation alone.
